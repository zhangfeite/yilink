## 二、Wave 5 任务清单（两周）

### A. 安全止血（Codex Top5 对应）

1. 注册改**邀请码制**（`INVITE_CODES` env，逗号分隔；保留双入口但统一校验）+ 登录失败统一文案
2. **审核不再空壳**：默认违禁词库填充（金融荐股/成人/赌博/诈骗基础集）+ URL 域名黑名单最小集；`review` verdict 改为进入 `REVIEW` 状态不发布，管理员放行；公开页页脚举报邮箱
3. **发布状态机补洞**：已发布页的 PATCH/blocks 保存 → 重新机审 + `revalidateTag`（修复「改后不生效」与「先发后改绕审」两个孪生缺陷）
4. **统计止血**：blockId 归属校验；VIEW 按 ipHash+page+小时去重；`x-forwarded-for` 只信 Cloudflare 注入头；文档化 Cloudflare WAF 限频规则配置（register/login/api-e）
5. **数据闭环**：GitHub Actions 每日定时触发受保护的 rollup/prune 端点 + `wrangler d1 export` 每日备份；留存窗口 90→30 天；`Order.raw` 精简为必要字段；PRD 隐私措辞改为与实现一致；staging 恢复演练一次
6. 健康检查加 DB 读；页面删除改 30 天软删除
7. CI 补 `cf:build` + E2E + 「review 不上线/已发布修改必审」不变量测试

### B. 门面与转化（Kimi 缺口 ①②③）

8. 营销首页真实化：产品截图 + 特性 + **定价区（含信任承诺五条）** + demo 链接；修 GitHub 断链；README 顶部 3 张截图 + demo 链接
9. **发布成功 → 自动弹出分发面板**（复用 share-panel：短链/二维码/海报/各平台文案）——用户情绪峰值时把分享工具递到手上

### C. 商业化通电（合议后的定价形态）

10. 套餐改造：FREE 3 页 / PRO_MINI $12 十页 / PRO $25 五十页 + 公平使用条款文案；设置页与定价区同步
11. LemonSqueezy 开户与商品创建（**用户动作**）→ env 通电

### D. 发布动作（第 2 周末）

12. V2EX「开源 + 邀请制公测」帖（用 Kimi 的标题与首段模板，附邀请码发放机制：帖内首批 + GitHub issue 领取）；掘金长文《微信内置浏览器 H5 适配实战》随后

**后置到 wave 6**：新 3 模板（跨境卖家/音乐人/求职季）+ 9 月秋招 drop、即刻/小红书、访客视角微信卡片预览、召回邮件、自定义域名。
