# Spec-02c：预览页增加「场景模板」演示层

> 工人：Kimi K3｜验收：Claude 本体（视觉评审 + 交互验证）｜上位文档：[template-system.md](design/template-system.md)、[design-direction.md](design/design-direction.md)
> 目标：在 `docs/design/theme-preview.html` 上增加第三层演示——场景模板切换，直观展示「同一骨架，不同人设」的模板机制。**只改这一个文件。**

## 1. 交付

在现有控制条（主题切换/布局切换/转化条开关）上方或同排新增「场景模板」切换组，3 个预设：

### 预设 A：插画师 · 约稿（现状即是，作为默认）
林小满 / cream-paper 默认主题 / 网格布局默认 / 现有区块组合 / CTA「+ 加微信合作」

### 预设 B：摄影师 · 约拍
- 身份：陈野 ｜ 人像·活动摄影师 · 约拍开放 ｜ 简介 2 行（写作示范式文案，自拟）
- 默认主题 ink-dark、网格布局
- 区块：约拍套餐与价目（LG 链接卡）、客片精选（MD 链接卡）、近期档期（MD 链接卡）、贴纸行（微信/小红书/微博/B站）、微信卡（转化条关时显示）
- CTA：「+ 加微信约拍」（点击复制 chenye-photo，toast 同现有机制）

### 预设 C：独立开发者 · 产品页
- 身份：阿枫 ｜ 独立开发者 · 正在做「一链」｜ 简介 2 行
- 默认主题 minimal-light、列表布局
- 区块：产品主页（LG）、更新日志 Changelog（MD）、贴纸行（GitHub/知乎/即刻占位用现有真图标子集：GitHub/知乎/B站）、微信卡
- CTA：「☆ GitHub 上 Star」（点击 toast「已复制仓库地址（演示）」）

## 2. 行为要求

- 切换预设 = 同时切换：身份区内容、区块组合、默认主题、默认布局、CTA 文案与复制内容；用户切换预设后仍可自由改主题/布局（预设只设默认值，不锁定）
- 预设数据结构照 [template-system.md](design/template-system.md) §二 的 template schema 写成 JS 对象数组（演示层与未来产品数据结构一致）
- 复用现有全部组件类与样式；**不新增视觉模式**；新按钮带 aria-label；仍零外部依赖

## 3. 验收

1. 3 预设 × 8 主题 × 2 布局随机抽查渲染正常，八条法则与反面清单不破
2. 预设切换后默认主题/布局正确联动，且手动改主题不被预设重置
3. 转化唯一性联动在 3 个预设下都成立（转化条开→微信卡收起）
