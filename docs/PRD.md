# PRD：一链（YiLink）——中文开源个人主页

> 版本 v0.2 ｜ 2026-08-04 ｜ 状态：已评审，四项决议落定（见文末「评审决议」）
> 依据：[调研总结](research-summary.md) 及五份分报告。产品名已正式确定：**一链 YiLink**。

---

## 1. 产品定义

**一句话**：开源的聚合主页工具——把一个人散落在全网的身份、内容与联系方式，装进一个「链接 + 二维码 + 海报 + 小程序卡片」四位一体的主页里。

**双重定位**：

- 对中文互联网：填补「多用户 bio-link 开源平台」的生态位空白，成为中文开源个人主页的事实标准。自部署优先，天然规避域名连坐与平台单点风险。
- 对出海人群：一个对中国用户友好的 Linktree 替代品（国内可访问、中文界面、微信/支付宝元素、买断制收美元）。

**开源承诺**：核心全部开源（Apache-2.0），云托管只是可选便利，不是功能墙。

### 1.1 非目标（明确不做）

| 不做 | 原因 |
|---|---|
| 防封短链、域名轮换、防红等对抗性功能 | 微信规范明文定义为恶意对抗，且是灰产标签，一票否决 |
| 基于个人微信协议的自动化（自动回复/群控） | wetool 死案，帮信罪风险 |
| 国内 C 端展示型订阅收费 | 十年反复证伪（见调研总结） |
| 站内评论/留言（MVP 阶段） | 触发《互联网跟帖评论服务管理规定》全套义务，收益不匹配 |
| 支付/收款能力（MVP 阶段） | 涉支付合规与 B25 许可，V2 再评估（优先接第三方而非自建） |
| 免费版抽成、水印勒索、封号公开羞辱 | 竞品的信任伤疤，反向承诺（§5） |

## 2. 目标用户

### P0：出海创作者与跨境从业者（付费主力）

在 TikTok / Instagram / YouTube / X 运营的中文创作者、跨境电商卖家、独立开发者。bio 里真的能放链接；Linktree 国内访问不稳、订阅要美元信用卡。**付费意愿最高（赚美元、按美元锚定），是托管版的目标客群。**

### P1：接单型自由职业者与博主（国内场景验证者）

约拍摄影师、插画师、咨询顾问、家教、手艺人、"全网同名"跨平台博主。场景：微信里被问"你都有什么作品/怎么收费"时甩一张主页；线下活动立一个码；商务对接时发 media kit。**验证国内私域名片场景，主要用免费版/自部署。**

### P2：开发者与极客（社区引擎）

想要 about-me 页、愿意 Docker 自部署、会提 PR。**不是付费用户，是开源社区、口碑与贡献的来源，优先级不能排最后。**

反面人群（不服务）：纯商务名片交换（递名片证伪）、想绕平台风控导流的灰产用户（主动风控排除）。

## 3. 核心用户旅程

1. **建页**：注册（自部署：邮箱/GitHub OAuth；托管国内版：手机号实名）→ 选模板 → 填昵称/头像/简介 → 添加区块 → 发布，全程 ≤ 5 分钟（对标 Linktree onboarding，竞品验证的及格线）。
2. **分发**：复制短链接（简介/私信用）→ 下载页面二维码与分享海报（线下/群/朋友圈用）→（V2）转发小程序卡片（微信会话用）。
3. **被访问**：访客在微信内点开 → 直接正常渲染（生死线）→ 点击链接卡跳转 / 一键复制微信号 / 长按识别上传的微信二维码。
4. **回访经营**：创作者看数据（PV/UV/各链接点击/来源平台）→ 调整区块排序 → 数据导出。

## 4. 功能需求（分期）

### 4.1 MVP（首个开源版本，目标 6-8 周）

**主页编辑器**
- 区块类型：链接卡片（标题/描述/缩略图/URL）、社交图标行、纯文本、图片、分割线、**微信号复制块**（一键复制 + 可选上传微信二维码图）、**二维码展示块**
- 拖拽排序、显示/隐藏开关
- 移动端优先的编辑体验（创作者在手机上运营——竞品验证）

**国内平台图标体系**（无任何现有开源项目做过，核心资产）
- 首批 ≥ 30 个：微信、公众号、视频号、企业微信、抖音、小红书、B站、快手、微博、知乎、即刻、豆瓣、得物、淘宝、京东、拼多多、闲鱼、网易云、QQ音乐、播客（小宇宙）、GitHub、掘金 + 海外主流（TikTok/IG/YouTube/X/Spotify…，服务出海人群）
- 组织方式借鉴 littlelink（MIT）的按钮规范体系，内容全部自建

**主题与布局**
- 布局两种：经典列表 + **简化网格**（固定模式的 2 列拼贴，区块可选大/中/小尺寸——吃 Bento 情绪红利；自由拖拽网格编辑器放 V1.1）
- 主题 ≥ 8 套，**默认即好看**（Liinks 验证：默认美 > 自定义自由度），中文字体排版优化
- **场景模板 ≥ 8 个**：主题 × 版式 × 预置区块与文案骨架，按职业/场景切分（插画约稿/摄影约拍/播客/独立开发者/博主总名片/咨询预约/小店导购/出海创作者）；onboarding 第一步选场景模板而非选主题，占位文案即写作示范——体系见 [template-system.md](design/template-system.md)

**渲染与微信适配（国内产品的核心差异化）**
- SSR 渲染（分享卡片 meta + SEO + 微信内首屏 < 1s）
- UA 检测：微信/微博内置浏览器降级策略——常态直接正常渲染；仅 App 下载类按钮改「复制链接」、域名异常期展示浏览器打开引导
- 站点无任何诱导分享话术模板；UI 不模仿微信原生样式（规范 2.16 红线）

**二维码与海报**
- 页面二维码生成（可下载 PNG/SVG，可嵌 logo）
- 分享海报生成（主页信息 + 码 + 模板底图），物料上引导语用「相机扫码」

**数据统计**
- PV / UV / 每链接点击、来源平台粗分（UA/referrer）
- 隐私底线：访客标识仅存日盐哈希；原始事件保留 30 天后仅存聚合
- 一键导出 CSV（信任承诺产品化）

**多用户与部署**
- 自部署默认**单用户模式**（部署者=页主，无 UGC 合规负担）；`MULTI_USER=true` 开启多用户 + 管理后台，文档明示境内多用户部署的备案与审核义务
- Docker Compose 一键部署（app + SQLite 默认 / Postgres 可选）、宝塔教程、Vercel 部署按钮（海外）
- i18n：zh-CN / en 双语（README 也双语——同时打中英文社区）

**内容安全（可插拔管道，托管版必开）**
- 接口化设计：本地敏感词库（默认）+ 阿里云/腾讯云内容安全 adapter + URL 域名黑名单 + 落地页抓取送审钩子
- 违规处理：先隐藏页面并通知整改（**不公开羞辱**）、站内申诉通道；金融荐股/医疗/成人等类目直接禁入
- 页脚举报入口

### 4.2 V1.x（开源版迭代）

- 自定义域名绑定（SEO 归用户 + 解决抖音企业号「备案主体一致」需求）
- 活码（渠道码：同一个码可变更目标、分渠道统计）
- 自由拖拽网格编辑器
- 模板画廊 + 模板页 SEO（`/templates/{persona}` 独立落地页，吃「约拍链接」「个人主页模板」类中文搜索）
- 主题社区投稿管道（主题即 JSON、投稿即 PR，CI 自动跑对比度/schema 校验并贴渲染截图；贡献者署名上画廊）+ 节令主题 drops（春节/毕业季/双十一等）
- Media kit 数据卡（粉丝数/报价/案例，手动维护起步——对标 Beacons，服务接商单场景）
- 统计增强：地域/设备/时段
- 微博外链备案指引 + 运营方主域名代备案（托管版用户全站可点击直达）
- 多页面（一个账号多张主页：个人版/商务版）

### 4.3 V2（形态扩展）

- **微信小程序名片版**（企业主体注册；定位「名片卡片 + 复制链接 + 二维码」，不做任意外链 web-view 跳板——个人主体无 web-view 权限，业务域名白名单限制）
- 预约/表单区块（约拍、咨询时段——接单场景闭环第一步）
- 收款：优先对接第三方（出海：Stripe/Gumroad 链接；国内：面包多 Pay 类合规通道），不自建支付
- AI 生成主页（从公众号/小红书主页/简历一键生成初稿）
- 团队/矩阵版（MCN 管理旗下达人主页——B 端方向）

## 5. 信任承诺（写进定价页与 README 的产品原则）

竞品每道伤疤 → 我们的承诺：

1. 数据随时一键导出，格式开放（Bento 关停、Milkshake 无导出之鉴）
2. 免费版永久可用、无抽成、水印可关（Linktree 12% 抽成之鉴）
3. 涨价永远对老用户保价（Linktree +67% 之鉴）
4. 违规先隐藏 + 人工申诉，绝不公开羞辱页（"ACCOUNT BANNED" 之鉴）
5. 开源本身即最终承诺：托管版死了，你随时可以自己部署带走一切

## 6. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 微信内置浏览器（X5/XWeb）首屏 < 1s；主页静态化/边缘缓存 |
| 可用性 | 「微信内可正常打开」作为核心 SLA 指标监控（拨测），目标 > 99% |
| 安全 | 全站 HTTPS；上传图片过审+压缩；防 XSS（用户自定义内容全部转义）；速率限制 |
| 合规（托管国内版） | 企业 ICP 备案 + 公安备案（上线 30 日内）+ 手机号实名 + 审核管道全开 + 日志留存 ≥ 6 个月；收费前办 B25 增值电信许可 |
| 合规（自部署） | 文档明示：境内部署需自行备案；个人备案不可做多用户/UGC；默认单用户模式即为此设计 |
| 隐私 | 独立隐私政策；最小必要采集；访客统计仅聚合；未成年人信息按敏感处理 |

## 7. 域名与风控策略（托管版生死线）

1. 控制台/官网域名与用户主页承载域名**分离**（故障隔离）
2. 主页域名短、可口播、好拼写（抖音/小红书简介只能放纯文本，靠用户手动输入）
3. 预备 2-3 个平行域名做**风险隔离分层**（信任分高的老用户/认证用户用主域名，新注册用隔离域名）——注意：这是风险隔离，不是封禁对抗；被拦截走官方申诉，绝不换域名硬刚（关联主体连坐条款）
4. 新账号信任分级：新号限制外链条数与敏感类目，行为正常后升级
5. 审核指标运营化：机审覆盖率 100%、人审时效、误杀申诉时效全部进 dashboard

## 8. 技术方案

### 8.1 选型与理由

| 层 | 选型 | 理由 |
|---|---|---|
| 全栈框架 | **Next.js（App Router）+ TypeScript** | SSR 是微信分享卡片与 SEO 硬需求；三大 MIT 代码矿（BioDrop/librelinks/littlelink-server）全是 React 系，搬运零摩擦；未来小程序走 Taro（React 语法）技术栈连续 |
| 数据库 | **Prisma + SQLite（自部署默认）/ PostgreSQL（托管）** | 自部署零依赖开箱即用；托管版平滑切换 |
| 统计 | 自研轻量埋点（参考 librelinks 的 MIT 实现）：原始事件表 + 定时聚合 | MVP 不引入 Redis/ClickHouse，控制部署复杂度 |
| 二维码/海报 | 服务端生成（qrcode 库 + satori/canvas 出图） | 海报模板与主题系统共用设计 token |
| 审核 | Provider 接口（local-words / aliyun / tencent / custom webhook） | 开源版不绑定任何云厂商 |
| 部署 | Docker Compose 一键 / Vercel 按钮 / 宝塔文档 | 覆盖国内自部署人群与海外用户 |
| API | API-first（REST，OpenAPI 描述） | 小程序、CLI、第三方集成的前置条件 |

### 8.2 代码复用清单（全部 MIT/BSD，合法搬运，NOTICE 致谢）

- **BioDrop**：多用户数据模型（用户/链接/统计）、组件组织、测试与 E2E 工程实践
- **librelinks**：主题系统与浏览/点击/地域/设备统计的轻量实现
- **littlelink**：品牌按钮 CSS 规范的组织方式（内容替换为国内平台体系）
- **littlelink-server**：Docker 化与环境变量配置化思路
- **红线**：LinkStack（AGPL）只作功能基准清单，代码一行不进仓库——写进 CONTRIBUTING.md 明示

### 8.3 数据模型（首版草案）

```
User(id, handle, email/phone, trustLevel, createdAt…)
Page(id, userId, slug, layout, theme, seoMeta, status[draft/published/hidden], …)
Block(id, pageId, type[link|social|text|image|wechat|qr|divider], position, size, config JSON)
ClickEvent(id, pageId, blockId?, tsBucket, uaClass, refererClass, ipHash)  → 聚合表 DailyStats
ModerationRecord(id, targetType, targetId, provider, verdict, reviewedBy?, …)
```
