# 一链 YiLink · 模板体系设计

> 2026-08-04 ｜ 上位约束：[design-direction.md](design-direction.md)（八条法则是所有模板的质量护栏）
> 回答的问题：Linktree 的「设计感 + 模板多」如何学习借鉴，以及如何借开源做出它做不到的模板飞轮。

---

## 一、拆解：Linktree 们的模板机制到底强在哪

| 机制 | 作用 | 对应证据（调研报告） |
|---|---|---|
| 模板按**职业/场景**切分（音乐人/播客/餐厅/小店…），不是按颜色切分 | 用户 5 分钟从「空白恐惧」到「像样的成品」，onboarding 转化的第一杠杆 | Linktree onboarding 是各评测第一肯定项 |
| 模板库本身是**营销面**：每个模板一个落地页，吃「XX 职业 link in bio 模板」的搜索流量 | 获客渠道，不只是产品功能 | Linktree /templates 体系 |
| **设计出圈**靠的是 Bento 式视觉而非 Linktree 本体（Linktree 自定义反被诟病） | 视觉差异是最低成本的传播钩子 | 竞品报告 §2.3：设计即差异化被 Bento 验证；其关停留下情绪真空 |
| 季节/文化限定主题（万圣节、Pride…）制造**上新节奏**和分享理由 | 老用户回访 + 社媒传播节点 | Linktree 季节性 drops |
| 用户晒页即传播（bento.me 链接在 Twitter 的晒图文化） | 每张好看的页面都是广告 | 竞品报告：免费主页自带 logo 病毒传播 |

结论：「模板多」是表象，机制是**降低起步成本（结构预置）→ 制造传播理由（好看+上新）→ 反哺获客（模板页 SEO）**的循环。

## 二、我们的三层模板架构

```
第 1 层  主题 Theme（视觉 token）        —— 8 套起步，社区可投稿扩充
         × 固定骨架（八条法则锁死质量下限）
第 2 层  版式 Layout（结构骨架）         —— 列表 / 简化网格（V1.1 自由网格）
第 3 层  场景模板 Template（人格化成品） —— 主题 × 版式 × 预置区块 × 文案骨架 × 默认 CTA
```

**场景模板 schema**（静态 JSON 资产，进仓库不进数据库）：

```json
{
  "id": "illustrator-commission",
  "nameZh": "插画师 · 约稿",
  "persona": "创作者",
  "scene": ["约稿", "作品展示"],
  "defaultTheme": "cream-paper",
  "layout": "grid",
  "cta": { "type": "wechat", "label": "加微信约稿" },
  "blocks": [
    { "type": "LINK", "size": "LG", "config": { "title": "作品集 · Portfolio", "desc": "插画与商业案例精选" } },
    { "type": "LINK", "size": "MD", "config": { "title": "约稿须知", "desc": "档期 / 报价 / 合作流程" } },
    { "type": "SOCIAL", "size": "SM", "config": { "items": ["wechat", "xiaohongshu", "bilibili", "weibo"] } },
    { "type": "TEXT", "config": { "markdown": "「占位文案给出写作示范，而不是 Lorem ipsum」" } }
  ]
}
```

要点：占位文案即**写作示范**（教用户怎么介绍自己），这是模板价值的一半；用户选模板后改字即可发布。

## 四、开源模板飞轮（Linktree 做不到的部分）

1. **主题即 JSON，投稿即 PR**：`themes/` 目录接受社区 PR；CI 自动跑对比度校验 + schema 校验 + 渲染截图贴进 PR 评论，人审只看「八条法则」符合度。低门槛已被 LinkStack 社区主题验证可行，但我们的 token 化设计门槛更低（改 JSON 不用写 CSS）。
2. **贡献者署名上画廊**：模板画廊每个社区模板挂作者名/主页链接——设计师投稿动机是曝光，正好用我们自己的产品当他们的名片（吃自己的狗粮）。
3. **官方精选 / 社区两档**：官方档全部人审过法则；社区档过自动校验即可上架，标注来源。质量分层，帅但不失控。
4. **节令 drops（中文互联网的独有节奏）**：春节红金、毕业求职季、七夕、中秋、双十一店主季——每季 2-3 套限定主题 + 配套海报模板，制造上新话题和回访理由。海外档期（圣诞等）服务出海人群。
5. **模板页 SEO**：V1.x 起每个模板独立落地页（`/templates/photographer` 等），吃「约拍链接怎么做」「个人主页模板」类中文搜索——这是国内竞品完全没做的获客面。

## 五、质量护栏（多样性不破坏高级感）

- 所有模板（含社区投稿）必须通过：schema 校验 → WCAG AA 对比度自动检查 → 反面清单人审（实心色块/emoji 图标/克隆脸版式等一票否决）
- 场景模板只能引用已通过审核的主题，不允许内联自定义视觉
- 官方模板每季度按数据汰换：选用率、发布完成率、7 日留存

## 六、落地排期（并入 PRD）

| 阶段 | 内容 |
|---|---|
| MVP | 8 主题 + **8 场景模板**（onboarding 第一步选场景模板而非选主题）；模板为静态 JSON 资产 |
| V1.x | 模板画廊 + 模板页 SEO；`themes/` 社区投稿管道（CI 校验+截图）；首个节令 drop |
| V2 | 模板市场（付费模板分成，对应 PRD §10）；AI 按公众号/主页内容生成个性模板 |
