# BENTO 自由布局 · 模板与文案配套

> 2026-08-10 ｜ 配套文档：[plan-free-layout.md](../plan-free-layout.md)（最终方案）、[design-direction.md](design-direction.md)（八条法则）、[advice-layout-kimi.md](../advice-layout-kimi.md)
> 适用范围：P2 阶段 8 个模板的 BENTO variant（经视觉评审后替换模板截图），以及 BENTO 编辑器 UI 文案。

## 坐标系速查

- 4 微列，`x ∈ {0,1,2,3}`，`x + w ≤ 4`；行高单位 12px，`h=4 ≈ 84px`（标准卡），`h=8 ≈ 180px`（高块），`h=1 ≈ 12px`（薄条）。
- 宽度纪律：内容块（LINK/TEXT/SOCIAL/WECHAT/QR）最小 `w=2`（半宽）；IMAGE 可做 `w=1` 小图；DIVIDER 固定 `w=4`。
- 排版纪律（承接八条法则与 plan §二）：
  - 每页通栏块（`w=4`）≤ 3，且不允许连续 3 张以上通栏相邻（对应护栏黄条①）；
  - 少孤洞：横带尽量铺满 4 微列，空洞行 ≤3（约 36px）——1–3 行的错位是 bento 想要的节奏，强行填满会退化成列表；
  - 首屏（y < 12，约一屏）内必须有视觉重点（大图或主角链接）；
  - 身份首卡 / 吸底 CTA / 页脚锁定，不参与布局，下表均不含这三者。

## 二、只有 BENTO 能表达的两种新形态

### 形态 A：通栏薄条 `{x:0, y:Y, w:4, h:1}`（约 24px 高）

GRID/LIST 时代最小的块也是一张卡片；BENTO 里 h 可以到 1，于是有了一条「不占卡片名额的横幅」。视觉上用注释层样式（12px 居中，可带 accent 色前缀符号），不做成实心彩条（法则 §1）。

**适用场景与文案示例：**

| 场景 | 文案示例 |
|---|---|
| 播客更新公告 | `🎙 Vol.201 已更新 · 点击收听` |
| 店主上新预告 | `周三晚 8 点上新 · 青花系列 12 件` |
| 博主一句 slogan | `全网同名 @茶小雾，在哪都能找到我` |
| 活动/快闪 | `8 月杭州线下分享会 · 报名通道已开` |

约束建议：每页最多 1 条，且不计入通栏块配额（它不是「卡」，是「行间注脚」）；纯 TEXT/DIVIDER 类承载，不可放按钮（转化唯一性，法则 §8）。

### 形态 B：高块 `{x, y, 2, 8}` 或 `{0, y, 4, 8}`（约 180px+）

旧三档尺寸里最高的 LG 也只有一档；高块让「竖向内容」第一次有了正当容器。

**适用场景与文案示例：**

| 形态 | 场景 | 内容示例 |
|---|---|---|
| 2×8 竖图（IMAGE） | 摄影师竖构图客片、插画师长卷局部、穿搭博主全身照 | alt：「胶片竖构图 · 西湖边的婚礼跟拍」 |
| 2×8 歌单/片单（LINK 或 TEXT） | 播客主放「必听 5 期」、博主放「本月循环歌单」 | 「开车必听 5 期 · Vol.132 / 88 / 200…」 |
| 4×8 通栏大图（IMAGE） | 店铺全景、作品横卷、活动海报 | alt：「工作室全景 · 拉坯间与窑房」 |

约束建议：每页高块 ≤ 1 个（两个以上竖向节奏会塌）；高块旁必须能用半宽块补满（编辑器吸附时校验，否则降级 h=4）；4×8 计入通栏块配额。

## 三、编辑器 UI 文案

### 1. 转换弹层（LIST/GRID → BENTO）

- **标题**：换成自由布局
- **说明**：把卡片摆成你想要的样子——拖动改位置，拉边角改大小。原来的布局会自动保留，随时可以换回来。
- **主按钮**：开始排版
- **次按钮**：再想想

### 2. 🎲 换个排法

- **按钮**：🎲 换个排法
- **提示**（首次悬停/点按说明）：在好看的范围内随机换一种排版。不满意就再点一次，每一步都能撤销。

### 3. ✨ 一键整理

- **按钮**：✨ 一键整理
- **提示**：把卡片排整齐、补上空缺、恢复推荐节奏。整理前会自动留一份快照，不满意可以撤销。

### 4. 护栏黄条（可忽略，不阻断）

| 触发条件 | 文案 |
|---|---|
| 连续 3 张以上通栏块相邻 | 大卡片一张接一张会有点挤，中间穿插半宽卡片会更透气。 |
| 第一屏内没有大图或通栏主角 | 第一屏还看不出重点，把最重要的那张卡放大、或挪到上面试试。 |
| 页面底部出现补不满的空缺 | 底部留了个空缺。想补上就点「✨ 一键整理」，想留白就忽略这条。 |

### 5. 阻断提示（唯一的硬阻断：二维码/操作控件被裁）

> 二维码被裁掉了一块，访客会扫不出来。把它调大、或移到空位上，再发布。

按钮：**去调整**（点击聚焦到该卡片；不修复则发布按钮保持禁用，不出第二个弹窗）。

## 五、实装修正记录（2026-08-10 真机视觉评审）

纸面坐标全部合规，但真机渲染出来仍有一批问题——**坐标合法 ≠ 内容装得下**。这一轮把「装得下」变成了可测的判据。

### 体检脚本

```bash
node scripts/bento-fit-check.mjs
```

测三件肉眼容易漏的事：内容是否溢出格子（半行截断在缩略图上看不出来）、单行描述是否被省略号吃掉关键词、版面有没有成片空洞。改模板坐标或文案后必跑。

**前置陷阱**：本地直接改 D1 不会让 `unstable_cache` 失效，页面会继续吐旧数据；只删 `.next/cache` 不够，要删**整个 `.next`** 再重启 dev。这一条坑了一轮，靠「把 h 改成 9 看页面跟不跟随」的对照实验才定位到。

### 修掉的渲染缺陷（CSS，全部限定在 `.bentoItem` 作用域内，旧版式零影响）

| 现象 | 根因 |
|---|---|
| 图注被挤出格子 | `figure` 与其内 `a` 都是 `height:100%`，figcaption 分不到空间 → 改 flex 列，图吃剩余高 |
| 横排链接卡描述恒定差一行，加多少高都没用 | `align-items:center` 时 `.linkText` 高度是内容高，其内 `flex-basis:0` 的描述塌成 0 → 改 `stretch` |
| 贴纸图标从格子顶部漏出去 | `align-content:center` 溢出时向上下两侧跑 → 改 `flex-start` |
| 半宽格贴纸换行溢出 | 净宽仅 133px，56px 图标每行只放得下 2 个 → 窄格缩到 36px、标题压一行、隐去说明 |
| 微信卡碎成「s…」「p..」 | 横排下微信号只剩 20 来像素 → 窄格改竖排 |
| 「点击复制微信号」渲染两遍 | `note` 的默认值与下方内置说明是同一句 → 去掉默认值（此项影响旧版式，属既有缺陷修复） |

底部淡出蒙版试过又撤掉了：文本恰好填满格子时它会把最后一行一起淡掉，看起来像没渲染完，比硬裁切更糟。

### 调整的坐标与文案

- 高度改为**实测最小合身值**（脚本上下扫描得出），不再靠公式估算——装饰高随标题行数浮动，常数必然算错。
- 引言块统一改为**全宽收尾带**：半宽格里一行只排三四个字，排版难看，且左右列高度差会在底部留下大洞。
- 新增排版规则：**整段高度上无邻居的孤块拉满宽**。bento 的错落该来自块与块的咬合，不是空场。
- 链接描述按实测宽度精简（保留具体数字，砍掉可推断的修饰）。
- 空洞行容忍度从「必须为 0」放宽到 **≤3 行（约 36px）**：1–3 行的错位正是 bento 想要的节奏，强行填满反而变回列表。

### 已知未修

小宇宙、喜马拉雅等平台在图标库里仍是 `source: pending`，渲染为灰底文字占位，与旁边全彩图标并列时不成体系。播客模板受影响最明显，另行跟进。
