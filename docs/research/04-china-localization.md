# 04 · 中国本地化调研：link-in-bio 聚合主页的平台政策、合规与设计要点

> 调研时间：2026-08-04（所有网络来源检索于当日；政策以官方页面当时展示版本为准）
> 结论标注约定：
> - **[确证]** = 有官方规范原文 / 官方帮助文档 / 权威媒体报道支撑的现行规则
> - **[社区]** = 从业者经验、工具商文章、实测帖等非官方口径，可能过时或带营销倾向
> - **[查不到]** = 本次检索未找到可靠信息，明确说明，不做推断

---

## 0. 执行摘要

在中国做类 Linktree 产品，最大的现实是：**「一个 URL 走遍全网」的前提在中国不成立**。各平台对站外链接普遍采取「白名单 + 场景限制 + 导流处罚」三件套。聚合主页 H5 真正可用的场景是：**微信一对一聊天/群聊（域名合规时）、线下二维码、各平台简介里的纯文本网址、公众号菜单/阅读原文**；而「主页可点击外链」在抖音只对企业号开放、在微博要企业认证+外链备案、在小红书基本不存在。产品必须围绕这个现实设计：二维码优先、微信内可打开是生命线（域名备案+内容审核=SLA）、简介纯文本网址是主要触达路径。托管版则要按「UGC 平台」标准做全套合规（企业 ICP 备案、公安备案、后台实名、内容机审+人审），因为链接聚合服务是黑产导流的高危滥用对象，一个恶意用户可能拖垮整个主域名。

## 1. 各平台外链 / 导流政策

### 1.0 大背景：2021 工信部「解除外链屏蔽」及实际执行

- **[确证]** 2021 年 9 月，工信部召开「屏蔽网址链接问题行政指导会」，要求阿里、腾讯、字节等平台限期解除网址链接屏蔽，否则依法处置（[21财经](https://m.21jingji.com/article/20210914/herald/3a98c39e195b8d8642ef15b4fbaf2afe.html)、[新浪科技](https://finance.sina.com.cn/tech/2021-09-18/doc-iktzqtyt6685990.shtml)）。
- **[确证]** 2021-11-29 微信据此更新外链管理措施：**点对点（一对一）聊天场景可直接访问外部链接；群聊场景「试行」开放电商类外链直接访问**；并计划提供用户自主选择模式（[新浪](https://news.sina.cn/kx/2021-11-29/detail-ikyamrmy5810122.d.html)、[腾讯新闻](https://new.qq.com/rain/a/20211130A04A5M00)）。
- **[确证]** 执行是渐进且不彻底的：政策一年多后，淘宝链接仍无法直接转发朋友圈、抖音分享到微信仍靠「火星文口令」（[知乎专栏，2023](https://zhuanlan.zhihu.com/p/609984958)）。真正的破冰发生在 2024 年：9 月淘宝正式接入微信支付（[证券时报](http://www.stcn.com/article/detail/1334516.html)），微信内可直接打开淘宝、抖音、闲鱼链接购买（[凤凰科技](https://tech.ifeng.com/c/8D8wQE7oKh0)、[澎湃](https://m.thepaper.cn/newsDetail_forward_15645029)）。
- **要点**：互联互通红利主要落在**大平台之间的电商场景**；对中小第三方 H5，微信的域名管控和内容规范从未放松，甚至在收紧（见 1.1）。

### 1.1 微信（核心，决定产品生死）

#### 1.1.1 场景规则

- **[确证]** 一对一聊天：可直接打开外部链接（2021-11 官方更新，见上）。
- **[确证]** 群聊：官方口径为「试行开放电商类外链直接访问」；**[社区]** 实际体验中，合规备案域名的普通链接在群聊里通常也能打开，但陌生域名可能出现「非微信官方网页」中间提示页，需再点一次继续访问。
- **[确证]** 朋友圈：外链可发、可打开，但受额外限制——《规范》明确「任何在朋友圈内传播的拼团类外链」全部禁止；诱导分享类内容会被「在朋友圈对相关内容做不可见处理」（即发布者可见、他人不可见的「仅自己可见」处理）。
- **[社区]** 微信内置浏览器（X5/XWeb）打开 H5 本身没有技术障碍，障碍全部来自域名/内容管控。

#### 1.1.2 《微信外部链接内容管理规范》现行版本要点

- **[确证]** 官方页面显示当前版本**更新并生效于 2025-10-23**（官方地址：[weixin.qq.com 外链规范](https://weixin.qq.com/cgi-bin/readtemplate?t=weixin_external_links_content_management_specification)，检索于 2026-08-04）。
- 禁止内容共 20 类（2.1–2.20），与聚合主页产品最相关的：
  - 诱导分享 / 强制关注 / 诱导下载跳转（含「金钱奖励诱导下载 APP」「强制弹窗要求跳转 APP」）；
  - H5 游戏、测试类（比手速、性格测试等互动裂变形式）；
  - 欺诈类（含**仿冒微信排版/域名**）；违法经营类（非法分销、无证药品/证券推广等）；
  - 非法获取用户数据（未经明示同意收集个人信息、获取微信关系链）；
  - **与微信功能相同或相似、页面风格易被认为来源于腾讯的内容**（对做「微信里的个人名片页」的产品是个隐性红线，UI 不要模仿微信原生样式）；
  - 兜底条款：「来源不明链接」「**未备案网站**」被列入其他用户权益风险类——**未做 ICP 备案的域名本身就是可拦截理由**。
- 处理措施（3.x）：限制链接直接打开 → 限制域名/IP 在微信内访问 → 停止传播 / 朋友圈不可见；对主体：功能限制直至永久封禁账号、域名、IP、分享接口。**首次违规可在拦截页点「申请恢复访问」提交申诉；「同域名下大量链接违规且未有效整改，腾讯有权对该域名采取处理措施」（域名连坐）；对同一主体及关联主体可「不再提供申诉渠道」**——这条针对的就是「换域名对抗」行为。

#### 1.1.3 域名被封的常见原因与申诉

- **[社区]**（综合 [阿里云开发者社区](https://developer.aliyun.com/article/1724512)、[拨测](https://www.boce.com/help/1312.html) 等工具商总结）被拦截三大类原因：
  1. 内容违规：诱导分享/关注、虚假营销、色情赌博、政治敏感、侵权；
  2. 安全风险：**域名未 ICP 备案**、钓鱼/木马、HTTPS 证书异常；
  3. 处罚性拦截：被举报达到阈值、黑名单、**同服务器/同主体其他站点违规「连坐」**。
- **[社区]** 申诉渠道：拦截页「申请恢复访问」入口、[腾讯客服外链 FAQ](https://kf.qq.com/faq/170118UnqeUZ170118mUb6fu.html)、[微信安全中心](https://weixin110.qq.com/)、邮件 weixin@tencent.com、客服电话 0755-83765566。**[社区]** 实际成功率不高、周期不定；市面「防封短链/防红域名」多为骗局或灰产（[知乎](https://zhuanlan.zhihu.com/p/105350895)）。
- **[确证]** 大厂也会被封：2020 年 3 月飞书全部相关域名被微信封禁并被关闭分享 API，理由是「诱导分享、被多人投诉」（[21财经](https://m.21jingji.com/article/20200304/herald/1238badb52c16ecc7f048adb99740a11.html)）；淘宝、抖音、快手、拼多多、多闪、微视等均有被封史（[新浪科技《微信七年封链史》](https://tech.sina.com.cn/i/2020-03-06/doc-iimxxstf6775344.shtml)）。含义：**封域名是微信的常规武器，不是小概率事件**。

#### 1.1.4 小程序作为微信内载体

- **[确证]** **个人主体小程序不支持 web-view 组件**（内嵌 H5），只有企业等非个人主体可用，且需在后台配置「业务域名」（域名须 ICP 备案 + 放置校验文件，https）（[微信开放社区/开发者总结](https://blog.csdn.net/Ever_____/article/details/123884677)）。
- **[确证度：高，官方开发文档长期要求（本次未单独抓原文）]** 含 UGC 的小程序被要求自建内容安全机制，微信提供免费的 `security.msgSecCheck`（文本）/ `security.imgSecCheck`（图片）检测接口；社交/社区类目对主体资质审核严格。
- 含义：小程序版必须以公司主体做，且小程序内跳转任意用户自填外链受业务域名白名单限制——**小程序适合做「名片展示 + 二维码 + 复制链接」，不适合做「任意外链跳板」**。

#### 1.1.5 视频号（补充）

- **[社区]** 主页/私信直接放二维码、微信号会被限流/封号；合规路径是**视频号主页绑定公众号**，用公众号做私域承接（[人人都是产品经理](https://www.woshipm.com/operate/6201594.html)、[社群运营百科](https://www.ishequn.net/article/454)）。

### 1.2 微信公众号

- **[确证]** 自定义菜单「跳转网页」：**已认证订阅号、非个人主体服务号可填任意外部 URL**；未认证订阅号只能选择已有素材/已群发文章，个人主体服务号不能跳外部网页（[微信开放社区官方帖](https://developers.weixin.qq.com/community/develop/doc/000aa2560c8f2055d9791310753409)）。
- 文章内正文插入外链：**[社区，口径不一]** 一种说法是仅「开通微信支付能力的服务号」可插任意外链，认证订阅号只能插公众号文章链接（[yiban.io](https://yiban.io/blog/14900)）；也有资料称认证公众号均可。**以后台编辑器实际能力为准，本次未找到官方成文规则。**
- **[社区，多来源一致]** 「阅读原文」位置：所有公众号（含未认证）均可放任意外链，是最通用的外链出口。
- 含义：公众号（认证主体）是微信生态里**合法外链能力最强的载体**——菜单、阅读原文、自动回复文本链接都可指向聚合主页。

### 1.3 抖音

- **[确证]** **个人账号主页不能放可点击外链**。主页外链（官网链接/落地页）是**企业号（认证蓝V）权益**：需在 e.douyin.com 配置，链接必须 https、**ICP 备案主体与认证主体一致、不接受个人备案**，且除京东/天猫/淘宝企业店铺外不得涉及商品售卖（[企业号权益教程](https://xcx.iyong.com/2596628652474688/displaynews.html?id=2823044855776128)、[抖音开放平台](https://developer.open-douyin.com/forum/share/post/66cd3c69120df693b1d048e4)）。→ **用户把自己的聚合主页挂上抖音主页这条路，对普通创作者不通**。
- **[社区]** 简介/私信留微信号：平台《社区自律公约》禁止私信发送第三方联系方式、诱导跳转其他平台；三层风控（敏感词「微信/VX/加我」识别、频率行为模型、举报）；处罚阶梯：限私信 7 天 → 禁言/降权/限流 → 永久封私信乃至封号（[新榜](https://a.newrank.cn/trade/news/4919)、[拓客吧实测](https://www.tuokeba.com/jingyan/804.html)）。
- **[社区]** 粉丝群：禁止发第三方平台二维码、链接；官方已封堵「图文链接卡片」类工具，相关工具均有违规风险（[蚁小二](https://xueyuan.yixiaoer.cn/article/31295)）。
- **[确证]** 抖音小程序：**仅企业、个体工商户可注册，个人主体不开放**；特定类目需行业许可证，平台型可能被要求 ICP 备案/ICP 许可证/EDI（[抖音开放平台主体认证标准](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/operation/miniapp-creation/Subject)、[有赞](https://www.youzan.com/cms/article/70449.html)）。

### 1.4 小红书

- **[确证]** 管控最严。2024-11 发布「最严导流治理规则」（[腾讯新闻](https://news.qq.com/rain/a/20241108A064R300)、[人人都是产品经理](https://www.woshipm.com/share/6138360.html)）；2025-03-12《交易导流违规管理细则》生效（[网经社](https://www.100ec.cn/detail--6647740.html)）：打击范围包括在笔记、直播、评论区、私信中发布**定向联系方式（手机号、微信、邮箱、二维码）、第三方平台名称、网址链接**；处罚阶梯：警告整改 → 限流/限发布/限直播 → 封号；商家另有违约金、清退。
- **[确证]** 2025-01-07 起商家私信不得直发联系方式；合规留资路径是**专业号（企业号）+ 聚光投放的「私信通」留资卡/名片组件**（[企业微信指南](https://weibanzhushou.com/blog/29358)）。
- **[确证]** 2024–2026 的「放松」只发生在**电商外链**：2025 年与淘宝天猫（「红猫计划」）、京东、拼多多打通，**广告投放笔记（CID/UD）、评论区挂链**可跳外部电商 App，普通用户可挂「已购商品」链接；且限大快消、运动户外、大健康等部分类目、要求淘宝店铺体验分≥4.5（[36氪](https://36kr.com/p/3283806143373956)、[21经济网](https://www.21jingji.com/article/20250515/herald/e90b956ab96363a63e3ca921e948124d.html)）。**对「个人导流私域/自有主页」没有任何放松。**
- **[社区]** 灰色做法：简介留邮箱（相对安全）、背景图放二维码（有被识别风险，图片 OCR 在风控范围内）、评论区引导私信；简介里的网址是纯文本不可点击，且「聚合链接不触发联系方式检测」属于工具商营销话术，不能当平台承诺（[搜狐](https://www.sohu.com/a/822009336_121911128)、[5acxy 营销文，需甄别](https://www.5acxy.com/blog/si-da-pingtai-yinliu-guize-juhe-lianjie-fangfa.html)）。

### 1.5 B站

- **[社区]** 个人简介、置顶评论可放链接文本；「蓝链」（合规带货/推广链接）需平台审核，普通 UP 主可用于与视频强相关的合法站点；**未经许可直接跳转微信/QQ 私域的链接是审核红线**；评论区普通链接常被屏蔽（[腾讯云开发者社区转载文](https://cloud.tencent.com/developer/news/2525687)、[知乎](https://zhuanlan.zhihu.com/p/549339444)）。**[查不到]** B站关于简介外链的成文官方规则本次未检索到，以上为从业者口径。
- **[确证]** 2025 年 B站在淘宝天猫全域合作（外链电商）名单中（阿里高管口径，见 1.4 来源）。

### 1.6 微博

- **[确证]** 2020-07 起实行**外链白名单机制**：仅政府（*.gov.cn）、教育（*.edu.cn）、央媒、主要互联网平台主域名自动白名单；其他域名不支持直接跳转（[新浪科技](https://tech.sina.com.cn/digi/2020-07-08/doc-iircuyvk2699498.shtml)；官方规则页：[微博外链管理规范](https://m.weibo.cn/outlink_rules.html)——白名单/风险提示/限制/禁止四级，未白名单但机审无风险的链接可临时放行 7 天）。
- **[确证]** 上白名单路径：**企业认证（600 元/年）+ 外链备案（提供 ICP 备案号）**，通过后该域名链接可在微博内直接打开；未备案链接显示「访问的网址不受信任」提示页，用户需手动复制到浏览器（博客园 2025-06 实测全流程：[cnblogs](https://www.cnblogs.com/cmt/p/18929466)）。
- 含义：**你的产品域名可以作为运营方做一次企业外链备案，让所有用户主页链接在微博可点击直达**——微博是少数「花钱+备案就能正经解决」的平台。

### 1.7 快手

- **[确证]** 《用户资料规范》：账号昵称、简介、头像、封面**不得含微信等联系方式或其他平台导流信息**（[快手社区规范官方页](https://www.kuaishou.com/norm?tab=userInfo)）。主页可点击外链能力与商家号（企业认证）绑定，行业准入有禁入清单（[商家号认证手册](https://shuaishou.com/school/infos49311.html)）。**[查不到]** 快手普通个人主页挂链接的官方成文规则本次未检索到，从业者普遍按「不可」处理。

### 1.8 知乎

- **[社区]** 相对宽松：个人简介可留公众号名称等信息，社区经验认为 1000 粉/1000 赞后留公众号相对安全；**回答正文放微信号会被直接处理（小黑屋）**；批量插外链/评论区发链被判垃圾营销，轻则限流重则封号（[米哥说淘客](https://www.migeshuo.com/%E7%9F%A5%E4%B9%8E%E5%BC%95%E6%B5%81%E7%AC%AC2%E7%AB%A0-%E7%9F%A5%E4%B9%8E%E8%B4%A6%E5%8F%B7%E6%80%8E%E4%B9%88%E8%AE%BE%E7%BD%AE%E9%99%8D%E4%BD%8E%E5%B0%81%E5%8F%B7%E9%A3%8E%E9%99%A9%EF%BC%9F/)、[运营派](https://www.yunyingpai.com/content/507113.html)）。
- **[确证度：高（产品常识）]** 知乎站外链接点击会经 link.zhihu.com 中间确认页跳转，但可达。2025 年知乎也在阿里全域合作名单中。

### 1.9 结论：聚合主页 H5 在中国的实际可达性

| 场景 | 可达性 | 说明 |
|---|---|---|
| 微信一对一聊天发链接 | ✅ 直接打开 | 前提：域名已 ICP 备案、内容合规、未被拦截。**这是第一分发场景** |
| 微信群聊发链接 | ✅/⚠️ 基本可开 | 官方仅「试行」电商类直访；陌生域名可能有中间提示页 |
| 朋友圈发链接 | ⚠️ 可发可开 | 传播弱（无卡片大图）；诱导分享即「仅自己可见」处理 |
| 公众号菜单 / 阅读原文 / 自动回复 | ✅ | 需认证公众号（菜单）；阅读原文无门槛 |
| 线下二维码（易拉宝/名片/屏幕） | ✅✅ 最优 | 系统相机扫码走系统浏览器完全无限制；微信扫一扫走内置浏览器、受域名规则约束 |
| 抖音主页 | ❌ 个人不可 | 仅企业号可挂官网链接，且要求企业 ICP 备案主体一致 |
| 抖音/小红书 简介 | ⚠️ 纯文本 | 只能放不可点击的短域名文字，靠用户手动输入；小红书连文本网址都在打击范围 |
| 小红书全场景 | ❌ 基本不可达 | 最严；仅企业号留资组件、广告电商外链例外 |
| 微博 | ✅（运营方代办） | 产品方做企业认证+外链备案后全站可点击直达 |
| B站简介/置顶评论 | ⚠️ | 文本/审核蓝链；跳私域是红线 |
| 知乎简介/文章 | ✅/⚠️ | 相对最宽松，有中间跳转页 |
| 快手资料区 | ❌ | 资料区禁导流信息 |

**总结论**：聚合主页在中国的定位不是「放在每个平台主页上的那条链接」，而是**「私域会话里发的那张名片 + 线下扫的那个码 + 简介里那行可搜索的短域名」**。产品价值锚点应从「bio 里的 link」平移到「私信/群/二维码里的 link」。

## 2. 合规清单（托管版运营场景）

### 2.1 ICP 备案：个人备案基本不可行，必须企业备案

- **[确证]** 境内服务器提供 Web 服务必须先 ICP 备案（非经营性）；未备案不得提供服务（[阿里云](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/not-for-the-record-shall-not-provide-non-operational-internet-service)）。个人备案与企业备案在主体材料、责任承担上不同（[阿里云：备案类型选择](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/how-to-choose-the-record-type)）。
- **[确证（管局实践口径）]** **个人备案网站不得含交互式功能**：论坛、评论、聊天、留言板等被多省管局禁止，甚至「博客」字样、评论/登录功能都被要求去除，发现可注销/阻断备案（[CSDN 汇总](https://blog.csdn.net/wo541075754/article/details/104760235)、[百度智能云文章](https://cloud.baidu.com/article/3051091)、[SEO私馆](https://www.seosiguan.com/post/1033.html)）。**UGC（用户建主页=典型 UGC + 账号体系）用个人备案不可行，必须企业主体备案。**
- **[确证]** 若收费（会员、订阅、增值功能）即属「经营性互联网信息服务」，需在 ICP 备案基础上办理**增值电信业务经营许可证（ICP 许可证，B25 类）**，「先备案、后许可」（[中企百通](https://www.miibt.com/show-48-4172-1.html)、[知乎](https://zhuanlan.zhihu.com/p/701915310)）。注：B25 对外资股比有限制，融资结构需提前考虑。
- 连带约束：**抖音企业号挂外链要求「ICP 备案主体与认证主体一致」**（见 1.3）——意味着若你想让企业用户把聚合主页挂上抖音，主页需支持绑定客户自己备案的自定义域名，或该功能只面向你自己主体的官方页面。

### 2.2 公安备案

- **[确证]** 网站开通后 **30 日内**须在「全国互联网安全管理服务平台」(beian.mps.gov.cn) 提交公安联网备案，通过后在页面底部悬挂公安备案号（[阿里云](https://help.aliyun.com/zh/icp-filing/basic-icp-service/the-public-security-network-for-record-and-cancellation)、[腾讯云](https://cloud.tencent.com/document/product/243/19142)）。含交互服务（评论、UGC）的网站在备案表单中需如实勾选「交互式服务」类型，部分地区网安有额外核查。

### 2.3 内容治理义务（把自己当 UGC 平台看）

- **[确证]** 《网络信息内容生态治理规定》（网信办，2020-03-01 施行）：平台承担信息内容管理**主体责任**，须建立：用户注册与账号管理、**信息发布审核**、跟帖评论审核、版面页面生态管理、**实时巡查**、应急处置、网络谣言与黑产信息处置、用户信用管理、便捷投诉举报入口、年度治理报告（[官方全文](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm)）。用户主页的标题、简介、头像、链接文案都属「信息内容」。
- **[确证]** 《互联网跟帖评论服务管理规定》（2022 修订，2022-12-15 施行）：**「后台实名、前台自愿」**，须基于手机号/身份证/统一社会信用代码认证，未认证不得提供跟帖评论服务（[网信办](https://www.cac.gov.cn/2022-11/16/c_1670253725643572.htm)）。适用性：若产品开放访客留言/评论则直接适用；即使不开评论，《网络安全法》第 24 条对「信息发布服务」同样要求真实身份信息认证——**手机号注册实名是底线配置**。
- 若加入 AI 生成功能（AI 写简介等），另需对照《生成式人工智能服务管理暂行办法》（2023-08-15 施行）。

### 2.4 个人信息保护（PIPL）

- **[确证]** 要点（[中伦](https://www.zhonglun.com/research/articles/9266.html)、[君合](https://www.junhe.com/legal-updates/1390?locale=zh)）：独立隐私政策+首启弹窗同意；**最小必要**（收集类型、频率均最小化，「提升体验」不构成收集理由）；敏感个人信息**单独同意**；不满 14 周岁未成年人信息按敏感信息处理；托管版数据存境内，出境需评估。工信部 App 通报机制常态化，小程序/H5 也在 2025 年监管趋严范围内（[中伦 2025](https://www.zhonglun.com/research/articles/54860.html)）。
- 产品特有风险点：主页访问统计（访客画像）、第三方链接跳转参数——**不要把个人信息放 URL 参数**；访客统计以聚合数据为限。

### 2.5 内容安全工程做法与成本量级

- 通行架构：**发布时机审（云内容安全 API）+ 命中转人审 + 举报快速下架 + 存量巡查**；对链接类产品还要加一层 **URL 风控**：域名黑名单库、落地页抓取送审、跳转链追踪。
- **[确证]** 成本量级（2026-08 检索）：
  - 阿里云内容审核：文本标准版 **7.5 元/万次**、图片标准版 **15 元/万次** 起，资源包 60 万次 430 元 → 6 亿次 27 万元（6 折）（[阿里云计费文档](https://help.aliyun.com/zh/document_detail/477720.html)）。
  - 腾讯云天御：文本按量 **25 元/万条**，套餐包更低（[腾讯云 TMS](https://cloud.tencent.com/document/product/1124/37118)）。
  - 微信小程序场景可用官方免费 `msgSecCheck`/`imgSecCheck`。
  - 量级判断：百万级 DAU 之前，机审成本每月几百到几千元，**不构成成本障碍，构成的是工程与运营纪律问题**。

### 2.6 滥用与「域名连坐」风险（本产品最大生存风险）

- **[确证]** 微信规范明文：同域名大量违规未整改可整域处理；同一主体及关联主体可被取消申诉资格（见 1.1.2）。短链/跳转类服务是黑产（赌博、涉黄、诈骗导流）最爱的载体：新京报报道的网络色情引流即通过链接/App 分发（[新京报](https://m.bjnews.com.cn/detail/1728517185168507.html)）；微博因此对短链服务启用白名单（[超能网](https://www.expreview.com/75074.html)）。
- **[社区/报道，细节未独立核实]** 有案例称杭州某公司用 API 动态跳转传播赌博链接，技术负责人获刑 2 年（[CSDN 转述](https://blog.csdn.net/2503_92231666/article/details/148760496)）——即便细节存疑，「为黑产提供跳转技术支持可构成帮信罪」是确定的法律风险。
- **结论**：托管版 = 「所有用户共享你的域名信誉」。一个诈骗用户主页被举报，拦截的是你全体用户的主页。**审核不是合规成本，是产品可用性（SLA）本身。**

## 3. 中国用户现有做法调研

### 3.1 创作者的跨平台导流与身份聚合

- **「全网同名」**：**[社区]** 因链接跳不动，中国创作者的身份聚合主要靠「各平台简介写“全网同名 XXX”」，让用户去目标平台搜索——用**搜索代替超链接**。这是 link-in-bio 在中国最直接的替代品/竞品。
- **公众号为私域枢纽**：**[社区]** 主流打法是把各公域平台流量引到公众号（视频号绑定公众号入口、简介留公众号名），再用**自定义菜单 + 关键词自动回复**下发微信号/社群二维码/外链（[人人都是产品经理](https://www.woshipm.com/operate/5231904.html)）。
- **私域 SOP**：**[社区]** 公域合规钩子（主页背景图、直播口播「日常分享在微信」、抖音企业号私信卡片、小红书企业号留资组件）→ **企业微信活码**（自动分流入群，企微原生功能）→ 社群/朋友圈运营（[星云学院](https://www.iyouke.com/blog/1745.html)、[语鹦企服](https://crm.bytell.cn/blog/wework/1181)）。
- **wetool 教训**：**[确证]** 2020-05 微信封杀个人号外挂 WeTool，使用者大面积封号；行业共识转向「企业微信原生能力 + SCRM」，企微自带群活码、自动回复（[36氪](https://36kr.com/p/724297722775429)）。启示：**基于个人微信协议做自动化 = 死路；产品设计要贴官方能力（企微、公众号、小程序）**。

### 3.2 数字名片行业现状

- **[确证]** 行业存活且活跃：递名片（2017 年上线的电子名片小程序）、加推（toB 智能名片+CRM，服务 2.8 万+企业客户）等；2025 年仍有大量产品测评与新品，方向是「名片 + 客户追踪 + AI + CRM」（[36氪话题页](https://www.36kr.com/search-list/25774)、[知乎测评](https://zhuanlan.zhihu.com/p/1972630876081882813)；市场数据引自咨询机构转述，**可信度一般**）。
- 关键观察：中国数字名片的胜利形态是**微信小程序卡片**（在会话中以标题+缩略图卡片转发，无域名封禁问题、体验原生），而不是独立 H5 主页。toC 个人名片产品声量小，toB 销售场景（加推）才撑起了商业模式。
- **国内 link-in-bio 现状**：**[社区/营销内容]** 已有 Fixon、WeLink、KKLink、看否会（cs.kghui.cn）等小产品，卖点是国内访问快、「防微信拦截」、二维码、中文模板；Linktree 本身在国内访问慢/不稳定（[Fixon 博客](https://bbs.fixon.cc/archives/vs-linktree)、[5acxy](https://www.5acxy.com/blog/linktree-guo-nei-mian-fei-ti-dai-gong-ju-heng-ping.html)——均为竞品自荐文，需甄别）。**[查不到]** 未发现国内出现规模化（百万级用户）的独立 link-in-bio 产品。

## 4. 对产品设计的启示清单

1. **二维码优先，链接其次**。线下物料、直播贴片、屏幕展示是最无摩擦场景；把二维码生成/美化/带 logo/物料模板做成一级功能。注意：微信「扫一扫」仍走内置浏览器（受域名管控），系统相机扫码走系统浏览器（无限制）——**引导语写「用相机扫码」优于「用微信扫」**。
2. **「微信内可打开」当 SLA 经营**：域名企业 ICP 备案 + 公安备案 + 全站 HTTPS 是及格线；上线前后用拨测类工具持续监控域名在微信内状态；被拦截时走官方申诉而非换域名对抗（关联主体连坐条款堵死了轮换路线）。
3. **降级策略**：UA 检测微信/微博内置浏览器。首选是让页面在微信内**直接正常渲染**（这才是国内产品对 Linktree 的核心差异化）；「点击右上角在浏览器打开」遮罩引导仍是行业主流做法但体验差，只应在两种情况使用：APP 下载类按钮（微信内禁诱导下载→改为「复制链接」）、域名异常期。微博内非白名单链接会强制提示页——运营方应直接做企业认证+外链备案解决。
4. **小程序版：中期必做，但定位是「名片卡片」不是「链接跳板」**。小程序卡片是微信会话内传播的最优形态（数字名片行业已验证）；个人主体不能 web-view、任意外链受业务域名限制，所以小程序内做展示+复制链接+二维码，H5 承接完整功能。公司主体注册，预留 UGC 类目资质与 msgSecCheck 接入。
5. **托管版审核机制**：手机号实名注册（满足后台实名）→ 创建/修改主页时全部字段+链接 URL 机审（云内容安全 + 域名黑名单 + 落地页抓取）→ 命中人审 → 新账号限额与信任分级（新号先限制外链条数/敏感类目）→ 金融投资、医疗、荐股、成人等类目直接禁入 → 页脚举报入口 + 快速下架通道 → 日志留存（≥6 个月）。把「审核通过率/时效」做成运营指标。
6. **自托管开源版**：能把 ICP/公安备案与内容责任转移给部署者（部署者=网络运营者），但文档必须明示：境内部署需自行备案，个人备案做 UGC 不合规；默认关闭开放注册（单用户模式），多用户模式提示合规义务。这是规避平台责任的有效路线，也是社区增长路线（参考 LinkStack 等海外开源模式）。
7. **域名策略**：控制台/官网域名与用户主页承载域名**分离**；主页域名可预备 2–3 个平行域名做**故障隔离**（按用户信誉分层分配：认证企业用户用主域名，新注册用户用隔离域名），支持付费用户绑定自有域名（顺带解决抖音企业号「备案主体一致」问题）。再次强调：多域名是**风险隔离**手段，不是对抗封禁手段。
8. **重新定义 PMF**：在中国，「bio 里的链接」多数平台放不了，产品真正替代的是「微信名片/自动回复/全网同名」这套手工体系。主打场景应是：私信里发的个人主页、线下扫码的个人主页、简介里可搜索的短域名（域名要短、好读、能口播）。toB（企业员工名片、MCN 旗下达人矩阵页）比 toC 更可能先跑通商业化——数字名片行业已给出证据。
