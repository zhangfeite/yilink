# 境内部署合规指引

> 本文不是法律意见。它只整理 [中国本地化调研](../research/04-china-localization.md) 中已经列出的事实与产品启示，供部署前自查；请结合实际业务、部署地区和主管部门要求咨询专业人士。

## 适用范围

本文讨论在中国境内服务器上提供一链 YiLink 服务的情形，尤其是允许外部用户注册、创建主页和填写链接的多用户 UGC 形态。调研将这类托管服务视为高风险的链接聚合场景：所有用户共享同一域名信誉，违规主页可能影响整个域名的可用性。（来源：[调研 §2.6](../research/04-china-localization.md)）

## ICP 备案与公安备案

- 境内服务器提供 Web 服务前应先完成 ICP 备案；调研同时指出，个人备案与企业备案在主体材料和责任承担上不同。（来源：[调研 §2.1](../research/04-china-localization.md)）
- 调研汇总的管局实践口径指出，个人备案网站不得包含论坛、评论、聊天、留言板等交互式功能；用户创建主页和账号体系属于 UGC，因此个人备案不适合多用户 UGC 服务，应使用企业主体备案。（来源：[调研 §2.1](../research/04-china-localization.md)）
- 网站开通后 30 日内，应在全国互联网安全管理服务平台提交公安联网备案；通过后在页面底部悬挂公安备案号。提供交互服务时，备案表单需要如实勾选交互式服务，部分地区可能有额外核查。（来源：[调研 §2.2](../research/04-china-localization.md)）
- 若提供会员、订阅或增值功能等收费服务，调研指出还需在 ICP 备案基础上办理经营性互联网信息服务相关许可。（来源：[调研 §2.1](../research/04-china-localization.md)）

## <code>MULTI_USER</code> 的合规含义

调研将自托管开源版区分为单用户和多用户两类：默认关闭开放注册的单用户部署，面向部署者自己的页面；多用户部署则需要显式提示备案与审核义务。（来源：[调研 §4.6](../research/04-china-localization.md)）

因此，若将 <code>MULTI_USER=false</code> 作为部署形态描述，应只用于部署者自行管理的主页、且不向外部用户开放注册或代管 UGC。若采用 <code>MULTI_USER=true</code> 的多用户形态，则应按上文的企业 ICP/公安备案与 UGC 内容治理要求准备；该变量本身不能替代备案、实名或审核机制。（依据：[调研 §2.1、§2.2、§2.3、§4.6](../research/04-china-localization.md)）

## 内容治理与审核 provider

调研列出的内容治理义务包括用户注册与账号管理、信息发布审核、实时巡查、应急处置、投诉举报入口和年度治理报告。主页标题、简介、头像和链接文案都属于信息内容。（来源：[调研 §2.3](../research/04-china-localization.md)）

针对多用户部署，按调研中的通行架构配置审核流程：

1. 在发布时调用内容安全 API 进行机审，命中项转人工审核。
2. 提供举报后的快速下架流程，并进行存量巡查。
3. 对链接额外执行 URL 风控：域名黑名单、落地页抓取送审和跳转链追踪。

阿里云内容审核和腾讯云天御均被调研列为可选的云内容安全服务；部署者应根据自身业务选择 provider，并将密钥、计费、命中转人审和处置流程一并落实。（依据：[调研 §2.5](../research/04-china-localization.md)）

调研还指出，评论或留言场景涉及后台实名要求；即使不开放评论，提供信息发布服务也应考虑真实身份信息认证。多用户服务不应只依赖本地词库或单个配置开关。（来源：[调研 §2.3](../research/04-china-localization.md)）

## 上线前自查

- [ ] 已确认服务器所在地、主体与业务形态，并完成适用的 ICP 备案。
- [ ] 已在开通后 30 日内办理公安联网备案并展示备案号。
- [ ] 个人主体不提供多用户 UGC、公开注册或交互式服务。
- [ ] 多用户服务已准备注册与账号管理、发布审核、人工复核、举报和下架、存量巡查及 URL 风控。
- [ ] 对涉及评论或信息发布的功能，已核实实名要求。
- [ ] 已准备隐私政策、最小必要采集与统计数据处理方案。（来源：[调研 §2.4](../research/04-china-localization.md)）

平台外链规则会变化；上线前应按调研建议重新核对微信、抖音和微博等相关平台的现行规则。（来源：[调研文末时效提醒](../research/04-china-localization.md)）
