## 一、首发增长打法：中文社区怎么发、谁先谁后

### 0. 发帖之前的硬前提（做不到就不要发）

任何一条帖子都会把流量引到三个地方：GitHub README、营销首页、产品本身。目前这三处分别是——README 无截图无 demo 链接、营销首页是脚手架占位、「在 GitHub 查看」还链错到 github.com 首页（state 缺口 1、5）。**在开发者社区裸发一个门面残缺的项目，等于花钱请人来看你的毛坯房，第一波好奇心是不可再生资源。** 发帖前必须完成：

1. 修掉 GitHub 断链；
2. README 顶部放 3 张真机截图（编辑器 / 网格主题成品页 / 微信内打开效果）+ 一条在线 demo 链接；
3. 营销首页哪怕只有一屏，也要放真实页面截图而不是占位文案。

这是半天到一天的活，做完再谈发帖。

### 1. 各社区的角度与钩子

| 社区 | 人群匹配 | 发帖角度 | 钩子 |
|---|---|---|---|
| **V2EX 分享创造** | P2 开发者 | 「中文 link-in-bio 开源生态位是空的，我填了」+ Docker 一键自部署 + 微信内打开适配没人做过 | 自部署数据自主、Apache-2.0、坦诚列未完成项（V2EX 用户最烦吹牛，最赏坦诚） |
| **掘金** | P2，吃搜索长尾 | 技术长文：「微信内置浏览器 H5 适配实战：UA 降级、防反色、color-mix 兜底、SSR 分享卡片」+ 国内平台图标体系为什么要自建 30+ 个 | 工程细节即内容；文章挂 repo 链接，长期吃「微信 H5 适配」类搜索流量 |
| **即刻** | P1/P2 交界，独立开发+创作者 | 「Bento 关停之后，我给自己写了个更好看的」——晒网格主题成品页截图，讲 Bento 难民情绪与数据可导出 | 情绪钩子（Bento 关停真空）+ 视觉钩子（默认好看）；放真实页面链接让人点开体验 |
| **小红书** | P1 创作者 | 「约拍/约稿接单：5 分钟做一个作品合集主页，客户微信里直接点开」——图文/短视频晒页面，**不提开源** | 场景钩子（接单被问"作品在哪"的痛点）；简介挂短域名 |
| 少数派（可补充） | P1/P2 | 效率工具评测角度：「聚合主页的中国解法：二维码与海报一等公民」 | 工具方法论叙事，读者付费意愿高 |

英文线（Product Hunt / HN）按 PRD 既定走 "open-source link-in-bio, QR-first design"，不在本文展开，但注意它和 V2EX 可以同一天发，两边流量互不打架。

### 2. 首发顺序：V2EX 先发，掘金紧跟，即刻隔周，小红书押后

- **V2EX 先发**：P2 开发者是 PRD 定死的「社区引擎」，V2EX 是当天就能拿到真实技术反馈、第一波 star 和第一批 docker pull 的地方，发帖成本最低、容错最高（这里允许半成品，不允许虚伪）。即刻对完成度和审美的要求高得多，小红书更是直接考验微信分享链路——现在微信满血差配置（state 缺口 3、4），创作者来了点开分享卡片是 og 兜底丑卡、域名没备案随时可能被拦，**来了也是流失并留下差评，烧掉的是不可再生的人群口碑**。
- **掘金在 V2EX 后 2-3 天**：长文不需要快，需要的是质量；V2EX 反馈里被问最多的技术点，正好写进掘金长文。
- **即刻隔一周**：等 V2EX 一轮迭代把 README 和 demo 打磨好后，拿最好看的页面截图去打即刻。
- **小红书押后到微信满血之后**（AppID/Secret 配好 + 真机微信实测清单跑完）：小红书用户的转化路径 100% 经过微信，链路不通时投放是负资产。

### 3. 可直接用的发帖物料（V2EX 分享创造版）

**标题**：
> [开源] 一链 YiLink：可 Docker 自部署的中文 link-in-bio 聚合主页，针对微信内打开做了适配

**首段**：
> 把散落在各平台的自己装进一个页面：GitHub、掘金、公众号、B 站、小红书一次聚合，一个链接 + 一张二维码 + 一张分享海报发出去。起因很简单——国内同类工具要么停服要么丑，海外的在国内访问不稳，而「微信里能正常打开」「二维码/海报一等公民」这两件事没有任何开源项目做过，所以自己写了一个。Apache-2.0 全开源，Docker 一键部署数据在自己手里；8 套主题 × 8 个场景模板，5 分钟出页；数据随时一键导出。仓库公开刚 2 天，截图和在线 demo 在 README，求 star，更求拍砖——未完成项我直接列在下面了。

（注意遵守命名合规：全文不出现「Linktree」商标做对比宣传，用「link-in-bio」品类词。）

## 二、转化链上最伤转化的 5 个产品缺口（按伤害排序）

链条：访问落地页 → 注册 → 建页 → 发布 → 分享出去。

### 1. 分享环节在微信里是半残的（state 缺口 3+4，最重）

「分享出去」是这个产品唯一的病毒回路，而它的主战场是微信。现状：公众号 AppID/Secret 未配，转发卡片走 og 兜底（丑、无大图、无 JSSDK 增强）；更致命的是承载域名 yilink.app 经核实不可备案，而微信外链规范把「未备案网站」列为兜底拦截理由——**国内用户分享出去的每一条链接都头顶悬剑**。没有微信满血，产品的传播系数约等于 0，前面所有增长动作的 ROI 都被乘以 0。这不是优化项，是断电项。

### 2. 门面三重失血：README 无截图、营销页占位、GitHub 断链（state 缺口 1+5）

所有社区流量落地第一跳就是这三个地方。开发者看到无截图的 README 默认「项目还没做完」直接关掉；非开发者看到占位营销页不会产生任何注册动机。**漏斗最上端的洞永远是最贵的洞**，因为它漏掉的是你花钱/花脸面买来的流量。修复成本不到一天，优先级却高于任何新功能。

### 3. 发布成功时刻没有「分发大礼包」动线（我自己发现）

发布成功是这个产品唯一一次用户情绪峰值，也是引导分享的黄金 3 秒。目前二维码、海报能力都有，但从文档看它们是以「功能入口」存在的，而不是发布流程的终点动作——发布后应直接弹出一个分发面板：复制短链接 / 下载二维码 PNG / 下载分享海报 / 各平台一键分享文案，并把「下一步：把它发出去」做成发布成功的默认 CTA。用户不是不想分享，是你没在他最想分享的那一刻把工具递到手上。顺带把 state 技术记账里的海报 logo 合成补上——发出去的每张海报都是免费广告，广告上没有品牌是双重浪费。

### 4. 发布前缺少「访客视角」预览，用户不敢发（我自己发现）

这个产品的分享场景特殊：用户在意的是「别人在微信里点开看到什么」。编辑器实时预览是创作者视角，缺一个「访客视角模拟」——微信内打开效果 + 转发卡片长什么样 + 二维码扫出来什么样。看不见发出去的样子，用户会卡在「先不发，再改改」，而「再改改」的大多数结局是再也不发。发布按钮旁放一个「模拟微信打开」就能解决，成本远低于它的转化价值。

### 5. 分享之后没有召回钩子，统计是死数据（我自己发现）

链条严格说还有隐形的第六步：发出去之后用户回不回来看数据。目前统计采集和 30 天报表都有了，但没有任何主动触达——用户发布走人后，「你的主页本周被看了 47 次，最受欢迎的是作品集」这种邮件/站内提醒不存在。数据不变成通知，就只是后台里的数字；用户没有回访理由，就没有调整区块、二次分享、产生留存的循环。PRD 的 4 周留存 ≥ 25% 指标，没有这个钩子会很难看。

## 三、模板与主题的内容路线

### 1. 下一批 3 个场景模板

现有 8 个模板里 P0 付费主力只有「出海创作者」一个独苗，这是内容侧最大的倾斜。下一批按此纠偏：

1. **跨境卖家 · 店铺导航**（P0，最高优先）。PRD 把跨境电商卖家写进付费主力，但 8 个模板里没有一个服务他们：TikTok Shop / 独立站 / 亚马逊 / WhatsApp 客服 / 社媒矩阵一页聚合，CTA = 「Shop Now / 联系我们」。这是离钱最近的模板，也是托管版买断定价最该出现在旁边的页面。
2. **音乐人 · 新歌与演出**（P0/P1）。Linktree 模板体系里音乐人是全球验证的第一大类目，我们却缺席：新歌链接（网易云/QQ音乐/Spotify）、演出日程、MV 嵌入、社媒一行。它同时服务国内独立音乐人和出海人群，天然自带「晒页」传播属性。
3. **求职季 · 个人品牌页**（P1/P2，兼作节令钩子的载体）。金九银十秋招是接下来 3 个月中文互联网最大的确定性流量节点：简历 PDF 下载、GitHub/掘金/知乎作品、联系方式、一句话自我介绍。这个模板同时是掘金/V2EX 首波用户最可能「自己真用」的场景——让开发者吃自己的狗粮，是成本最低的口碑。

### 2. 第一期节令 drop 与 3 个月日历（2026 年 8 月 → 11 月）

节令日期以农历推算（2026-08-19 七夕、2026-09-25 中秋，官宣前务必再核一遍当年日历）。

| 时间 | 节点 | 动作 |
|---|---|---|
| 8 月中下旬 | 七夕（8/19，太近） | **跳过或只做 1 套社区投稿激活**。离现在不到两周，硬赶只会出一套半成品砸「节令 drop」这个机制的招牌——第一期 drop 的质量决定了用户对这个节奏的期待值 |
| 9 月上旬 | **金九银十 · 秋招求职季（第一期主推 drop）** | 2 套限定主题（建议：「offer 金」暖金系 +「简历蓝」冷静商务系）+ 配套分享海报模板 + 与上面「求职季」场景模板同步上线。选它做第一期而不是中秋：它与首波开发者/掘金用户人群完全重叠，drop 本身就能当一次掘金/即刻的二次发帖由头；中秋红金主题谁都能做，求职季主题只有吃透了用户人群的项目才会做 |
| 9 月底–10 月初 | 中秋（9/25）+ 国庆 | 1 套「月满」主题 + 1 套红金主题，轻量上线。中秋是微信转发高峰，主题本身即分享理由——前提是微信满血已通电，否则这套 drop 的传播力打三折 |
| 10 月下旬–11/11 | 双十一店主季 | 2 套导购向主题 + 小店/跨境卖家模板的海报配套，服务小店导购与跨境卖家两个离钱最近的场景 |

节奏原则：每期 2-3 套宁缺毋滥，drop 的价值在「制造回访理由和上新话题」，不在主题数量；所有 drop 主题走与常设主题相同的对比度/法则校验，限定 ≠ 降标准。

## 四、一条反直觉建议

**所有人都会劝你「开源项目先攒口碑，收钱的事以后再说」——恰恰相反：买断制收款必须在 M3 社区发帖的同一天通电，而且「$25 终身、永不涨价、老用户永远保价」要写进每一条发帖的标题或首段。**

理由三条：

1. **价格本身就是传播钩子，不是传播的障碍。** Lnk.bio 已经验证「买断 + 十年不涨价」精准收割订阅疲劳情绪——Linktree 全线涨价 67%、免费版抽成 12% 是这个品类人尽皆知的伤疤。你的定价页不是收银台，是一篇讨伐檄文；把 PRD §5 的五条信任承诺放在价格旁边，它就是你最有转发力的一张图。
2. **第一天透明定价，是「永不涨价」承诺唯一可信的起点。** 先免费攒一波用户再挂价格，无论多克制都会被解读为「养肥了收割」；第一天就明码标价，反而是对早期用户最诚实的交代。开源社区反感的从来不是收钱，是藏着掖着。
3. **收款通电是对商业前提的唯一真实验证。** state 文档写得很清楚：这个项目是「千 star + 每月数千美元」的量级，不是风投故事。既然天花板已知，就更需要尽早知道有多少人真的掏 $25——star 数验证不了任何商业假设，付款记录可以。纯攒 star 不验证需求，只是在攒虚荣指标。

对应动作：把 LemonSqueezy 开户与定价页从「商业化待办」提升为 M3 发帖的**阻塞项**，与修 GitHub 断链、补 README 截图同级。

## 总结（三行）

1. 发帖前先补门面（断链/截图/demo），首发顺序 V2EX → 掘金 → 即刻 → 小红书，小红书必须等微信链路满血，否则投放即负资产。
2. 转化链最大的洞不在注册也不在编辑器，而在「分享出去」：微信半残、发布时刻无分发动线、数据无召回钩子——这三处比任何新功能都优先。
3. 内容上把模板向「离钱最近的人」（跨境卖家/音乐人/求职季）倾斜，第一期节令 drop 押 9 月秋招季；买断制收款首日通电、价格写进标题——透明定价是信任资产，不是增长障碍。
